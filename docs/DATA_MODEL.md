# Data Collection and Format

## Workout

 - Date of the workout
 - Type of training day (push, pull, legs, upper, lower, etc.)
 - Workout length (in minutes)
 - Energy level (scale from 1 to 10)

## Exercise

 - Exercise name
 - Free weight or machine

## Set

 - Reps
 - Weight
 - Actual RPE
 - Warm-up or working set
