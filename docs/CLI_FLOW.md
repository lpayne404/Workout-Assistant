# Program starts

## Main Menu

1. Start Workout
2. Exit

## If "Start Workout":

 - Ask for training day type
 - Create empty workout
 - Show workout menu

Workout Menu
1. Add Exercise
2. View Workout
3. Finish Workout

## If "Add Exercise":

 - Ask for exercise name
 - Ask for equipment type
 - Add exercise to current workout

Exercise Menu
1. Add Set
2. Finish Exercise

## If "Add Set":

 - Ask for weight
 - Ask for reps
 - Ask for actual RPE
 - Add set to exercise

## When workout is finished

 - Show workout summary
 - Return to main menu
