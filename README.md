# Workout Assistant

## Project Goal

I want to create a tool to track my workouts and progress, personalized to my training style. Basic functionality should include stored lift history, progress, PR detection, and 1RM estimates. Eventually, I want to add AI-assisted insights.

## Why I'm Building This

I want a software development project to put on my resume that covers something I'm interested in and passionate about.

## Version 0.1 Scope

Basic command line workout logging (no memory yet). Create a workout, add exercises, add sets, and print a summary

## Non-Goals for Version 0.1

- Database storage
- Web interface
- User accounts
- AI features
- Charts
- Cloud sync

## Planned Features

Workout history, exercise history, volume tracking, estimated 1RM, PR detection, charts, web UI, AI analysis

## Tech Stack

Python -> SQLite -> FastAPI/web tech -> AI integration

## Development Philosophy

I want to understand each layer before adding the next one, rather than vibecoding; use Codex mainly for explanations, reviews, debugging, and guidance instead of having it build the whole thing. Unless I decide to launch this, Security is not a primary requirement for early local versions.
