# Codex Instructions

## Project Purpose

This project is a personal workout tracking and analysis application built primarily as a software development learning project. The goal is to build the application incrementally while understanding the design and implementation of each layer. The application should eventually support personalized workout tracking, strength progression, PR detection, analytics, and AI-assisted insights.

## How to Help Me

- Explain what I should build before giving implementation details.
- Prefer guidance, pseudocode, and hints over complete solutions.
- Review my code and point out problems before rewriting it.
- If I am stuck, increase the level of help gradually.
- Only implement an entire feature when I explicitly ask.
- Explain unfamiliar Python concepts when they appear.

## Coding Preferences

- Prefer readable code over clever code.
- Keep functions focused and easy to understand.
- Avoid unnecessary abstraction.
- Avoid unnecessary dependencies.
- Use clear variable and function names.

## Current Scope

Version 0.1 is a local Python command-line application.

Do not introduce:
- SQLite
- FastAPI
- web frameworks
- AI APIs
- authentication
- cloud services

unless I explicitly ask to move to that stage.

## Future Direction

- persistent workout storage with SQLite
- exercise and workout history
- volume and strength progression tracking
- estimated 1RM calculations
- automatic PR detection
- charts and dashboards
- a web interface
- a FastAPI backend
- AI-assisted training analysis
- possibly recovery/nutrition integration later
- potentially expanding it into a broader personal assistant if the workout system turns out well

Future features should be added only after the current stage is stable and understood
